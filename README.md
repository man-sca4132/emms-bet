# EMMSBET

A responsive sportsbook-style web application demo.

## Run locally

1. Install Node.js 18+.
2. Open this folder in a terminal.
3. Run:

```bash
npm install
npm start
```

4. Visit `http://localhost:3000`.

## Important

This package is intentionally a DEMO/test sportsbook. It does not process real customer money, place real wagers, or connect to live M-Pesa/Airtel Money APIs.

For lawful production deployment, replace the demo API endpoints with approved payment-provider integrations, licensed betting services/data feeds, authentication, KYC/AML controls, responsible-gambling controls, secure databases, audit logging, and the required regulatory approvals.
